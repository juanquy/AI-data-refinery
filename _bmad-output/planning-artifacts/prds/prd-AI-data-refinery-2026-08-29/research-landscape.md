# Landscape digest — Universal Data Refinery (researched 2026-08-29)

**1. Direct comparables.** All major web-data players now ship MCP servers; almost none ship severity-rated diffs or vertical pre-indexed corpora — that combination remains open. **Firecrawl** (Series A, $14.5M, Aug 2025 — [Tracxn](https://tracxn.com/d/companies/firecrawl/__AUIyUTgBhP2fuJfSidYDmsLSkPNv7XqK1ZuBMuVi3yw)) now covers scrape/crawl/search/map/schema-based extract plus a "Monitor" change-tracking job, via an [official MCP server](https://github.com/firecrawl/firecrawl-mcp-server); credit pricing ~$16–599/mo ([eesel](https://www.eesel.ai/blog/firecrawl-pricing)). No severity scoring on changes. **Jina AI** was acquired by Elastic (closed Oct 9, 2025 — [Yahoo Finance](https://finance.yahoo.com/news/elastic-completes-acquisition-jina-ai-130200685.html)); Reader remains token-priced with an on-prem SKU via Elastic ([xpay](https://www.xpay.sh/saas-pricing/jina-reader/)). **Tavily** was reportedly acquired by Nebius for $275M (Feb 2026, secondary source — [theaiagentindex](https://theaiagentindex.com/agents/tavily)); hosted MCP at mcp.tavily.com, credit-based. **Exa** has its own neural index (a general pre-indexed corpus), raised search to $7/1k (Mar 2026) and launched a per-run-priced Agent API in June 2026 ([TinyFish](https://www.tinyfish.ai/blog/exa-pricing), [fastCRW](https://fastcrw.com/blog/exa-pricing-explained)). **Context7** is Upstash's (not Mintlify's) free pre-indexed library-docs corpus over MCP, recently rearchitected for 65% less context bloat ([Upstash blog](https://upstash.com/blog/new-context7)); Mintlify separately auto-generates MCP servers for hosted docs (not re-verified this cycle). **Browserbase** ($68M raised; $40M Series B at ~$300M) is browser infra plus the "Director" automation agent; $20/$99/custom tiers ([browserbase.com/pricing](https://www.browserbase.com/pricing), [Upstarts](https://www.upstartsmedia.com/p/browserbase-raises-40m-and-launches-director)). **Apify** is the most agent-billing-native comparable: first-class MCP hosting, pay-per-event billing (`Actor.charge()`), agentic payments via x402/Skyfire so agents pay without an Apify account, 80% rev-share; rental pricing retires Oct 2026 ([apify.com/mcp/developers](https://apify.com/mcp/developers), [docs](https://docs.apify.com/platform/actors/publishing/monetize/pay-per-event)). **Diffbot** still sells the largest general pre-indexed structured corpus (10B+ entity Knowledge Graph) ([diffbot.com](https://www.diffbot.com/products/knowledge-graph)). **Bright Data** shipped a public MCP server (Aug 2025; 5k free req/mo) atop Unlocker (~$1.5/1k) and is pushing "Deep Lookup" for AI ([brightdata.com/pricing/mcp-server](https://brightdata.com/pricing/mcp-server)). **New entrants**: Parallel Web Systems ($100M Series A, ~$750M valuation; search+extract APIs for AI), Nimble ($47M Series B, Feb 2026; structured data feeds), Context.dev, Rindler ([data4ai](https://data4ai.com/blog/web-data-extraction/major-investments-in-web-data-for-ai/)). Generic change-detection (Visualping, Fluxguard) does AI summaries of diffs but not schema-validated, severity-rated, agent-consumable feeds ([Geekflare](https://geekflare.com/cybersecurity/monitor-website-changes/)).

**2. MCP ecosystem.** Mature and consolidating: Anthropic reported 10k+ active public servers and 97M monthly SDK downloads (Dec 2025); the official registry held ~9.6k latest server records by May 2026, with Glama (~37k tracked), Smithery (~7k, hosted), mcp.so and PulseMCP as discovery layers ([digitalapplied](https://www.digitalapplied.com/blog/mcp-adoption-statistics-2026-model-context-protocol), [TrueFoundry](https://www.truefoundry.com/blog/best-mcp-registries)). Monetization is nascent: reportedly <5% of servers earn revenue and global agent-to-tool payment volume is under $50K/day (secondary — [tooldirectory](https://tooldirectory.ai/blog/state-of-mcp-servers-2026)); billing rails are appearing (Moesif outcome-based MCP billing; Stripe "Machine Payments Protocol," Mar 2026). Auth standardized in the 2026-07-28 spec: MCP servers are OAuth 2.1 resource servers with RFC 9728 Protected Resource Metadata and RFC 8707 Resource Indicators required ([WorkOS](https://workos.com/blog/mcp-2026-spec-agent-authentication)) — enterprise-ready.

**3. Agent-native payments.** x402 crossed from speculative to real infrastructure, though dollar volume stays small. The x402 Foundation launched under the Linux Foundation (Apr 2026) with ~22 members including AWS, Google, Microsoft, Visa, Mastercard, Stripe, Anthropic ([Coinbase](https://www.coinbase.com/blog/coinbase-and-cloudflare-will-launch-x402-foundation), [BlockEden](https://blockeden.xyz/blog/2026/03/05/x402-foundation-ai-payment-internet/)); Coinbase claims 169M payments across 590K buyers/100K sellers in year one (vendor-reported); Cloudflare and AWS run x402 at the edge, and Cloudflare announced a "Monetization Gateway" (July 2026) ([InfoQ](https://www.infoq.com/news/2026/07/cloudflare-aws-x402-micropayment/)). Card-rail alternatives shipped in parallel — Stripe Shared Payment Tokens, Mastercard Agent Pay, Visa Intelligent Commerce — but consumer-side adoption is thin (ChatGPT Instant Checkout reportedly retired Mar 2026; unverified) ([Forbes](https://www.forbes.com/sites/boazsobrado/2026/03/19/stripe-visa-and-mastercard-race-to-build-ai-agent-payment-rails/)). Verdict: x402 micro-billing for B2B data APIs is a credible 2026 design choice (Apify already does it); treat subscriptions as the revenue base.

**4. Vertical incumbents.** Health-payer: **Policy Reporter** (Mercalis, rebranding under "Valeris") tracks payer medical/pharmacy policy changes with API access including historical documents and change insights ([policyreporter.com](https://www.policyreporter.com/solutions/policycore/)); **MMIT** (Norstella) sells a real-time payer coverage/restriction/policy-change API ([mmitnetwork.com/api](https://www.mmitnetwork.com/api/)); **MCG** (Hearst) sells UM criteria and prior-auth automation, not change feeds ([mcg.com](https://www.mcg.com/blog/cms-final-rule-prior-authorization-interoperability/)) — CMS-0057 deadlines (2026–27) are actively expanding this market. Zoning: **Zoneomics** (zoning API, [pricing tiers](https://www.zoneomics.com/pricing/api)) with **Regrid** distributing its standardized zoning layer ([regrid.com/zoning](https://regrid.com/zoning)); **Granicus** dominates municipal STR enforcement ([granicus.com](https://granicus.com/resource/evolving-short-term-rental-enforcement-how-data-is-driving-smarter-compliance/)). SEC: **AlphaSense** (agentic workflows via Accenture partnership), **Daloopa** (MCP connector for Claude for Financial Services Jul 2025, ChatGPT Feb 2026 — already "agent-ready"), **Fintool** ([Daloopa](https://daloopa.com/blog/analyst-best-practices/best-ai-tools-for-equity-research)). Takeaway: incumbents own the data but mostly sell dashboards/APIs to humans; only Daloopa and MMIT are meaningfully agent-native, so "AI-agent-ready change feeds" is a wedge in payer policy and zoning, and already contested in SEC filings.

**5. Regulated-data buyer expectations.** SOC 2 Type II is table stakes for any procurement conversation; health data additionally requires HIPAA eligibility with a signed BAA chain; buyers expect queryable audit trails of every agent/model action, action-level (not just authn-level) permission enforcement, RBAC, data residency options, and — new in 2026 audits — AI-specific evidence: model versioning, inference logging, drift monitoring ([Censinet](https://censinet.com/perspectives/ai-vendor-compliance-checklist-healthcare), [Ventus](https://www.ventus.ai/blog/soc-2-hipaa-ai-agents-security-architecture-enterprise-healthcare-2026-guide/)).

*Caveats: Tavily/Nebius, ChatGPT-checkout retirement, and MCP-monetization figures come from secondary/aggregator sources; x402 volume is Coinbase-reported. Primary-source pricing pages (Bright Data, Browserbase, Zoneomics, Apify docs) are current as retrieved.*
