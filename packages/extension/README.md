# 🧩 Universal Data Refinery - Chrome & Brave Browser Extension

A high-performance browser extension that distills any active webpage into **100% verified, strictly-typed JSON machine fuel** for autonomous AI agents in 1 click.

---

## 🚀 How to Install in Chrome / Brave / Edge

1. Open your browser and navigate to `chrome://extensions/` (or `brave://extensions/` / `edge://extensions/`).
2. Toggle **"Developer mode"** in the top-right corner.
3. Click **"Load unpacked"** in the top-left toolbar.
4. Select the directory:
   ```
   /media/juanquy/Dev/dev/Data-Refinery/packages/extension
   ```
5. The **Universal Data Refinery** icon will appear in your browser toolbar!

---

## ⚡ Features

* **1-Click Active Tab Ingestion:** Automatically reads the active browser tab URL.
* **Domain Presets:** Select between *Developer SDKs*, *B2B SaaS Pricing*, *Municipal Permits*, or *Universal Extraction*.
* **Custom AI Guidance Prompts:** Pass custom extraction instructions to Cloudflare Workers AI (Llama 3.3-70B).
* **Instant JSON Clipboard Copy:** Ready to paste into Cursor, Claude, or Python vector stores.
